Сайт на GitHub Pages не равнозначен публикации внутри VK: для запуска по `vk.com/app54823637` владелец приложения должен указать адрес в настройках и подтвердить конфигурацию.

Все **128 объектов**, координаты, описания, иллюстрации и карта высокого разрешения сохранены.

## Что сделать владельцу в VK Dev

1. Открыть <https://dev.vk.com/> и выбрать приложение **54823637**.
2. В настройках **размещения / адреса приложения** указать для мобильной версии, мобильного веб-клиента и десктопа одну и ту же **HTTPS-ссылку**:
   ```
   https://socman2023.github.io/podnebesie-map/vk/
   ```
   Названия полей в панели ВК могут отличаться. Пока можно оставить режим разработки/тестирования и не отправлять на модерацию.
3. Сохранить настройки и открыть <https://vk.com/app54823637> из приложения ВКонтакте. Проверить также <https://m.vk.com/app54823637>.
4. Проверить карту на обычном и складном смартфонах, а также на компьютере. Особое внимание: жесты, поиск, карточки, системная кнопка «Назад», «Поделиться местом», «В избранное».
5. Для публичного размещения подготовить иконку, обложку, описание и необходимые по актуальной форме скриншоты. Только после проверки отправлять на модерацию.

**Важно:** никакие пользовательские токены/секреты ВК не нужны для текущего HTTPS-размещения. Не отправляйте их в чат и не коммитьте в GitHub.

## Как работает адаптация

- Локально подключён VK Bridge 2.15.12, а Leaflet также хранится в репозитории.
- В среде ВК вызывается `VKWebAppInit`; в обычном браузере карта работает самостоятельно.
- Прямая ссылка `#place=academia` открывает Академию, а `#place=zlatograd` — Златоград.
- Выбор места синхронизируется с адресом и `VKWebAppSetLocation`; переходы назад обрабатываются через `popstate`, `hashchange` и `VKWebAppChangeFragment`.
- «Поделиться местом» создаёт ссылку `https://vk.com/app54823637#place=...` в среде ВК.
- Кнопка «В избранное» вызывается только внутри ВК.
- Учитываются системные отступы мобильного клиента.
- Персональные данные не запрашиваются и не сохраняются.

Браузерные автоматические тесты проверяют запуск вне ВК и работу с имитацией VK Bridge на экранах 320, 390 и 900 пикселей. Это **не заменяет** тестирование в настоящих клиентах ВК, особенно на iOS, Android и в десктопном клиенте.

## Альтернатива: VK Mini Apps Hosting

Для переноса с GitHub Pages на VK Hosting подготовлен конфигурационный файл:

```json
{
  "static_path": "build-vk",
  "app_id": 54823637,
  "endpoints": {
    "mobile": "index.html",
    "mvk": "index.html",
    "web": "index.html"
  }
}
```

Если понадобится именно VK Hosting, на компьютере разработчика:

```bash
npm run build
npm install --save-dev @vkontakte/vk-miniapps-deploy@^1
npx vk-miniapps-deploy
```

Для команды публикации потребуется авторизация владельца мини-приложения. **Развёртывание на VK Hosting сейчас не выполнялось**; к нему имеет смысл возвращаться только при необходимости после проверки уже размещённой HTTPS-версии.

## Дальнейшая работа

После подтверждения корректного запуска в ВК: при необходимости исправить особенности встроенного браузера, утвердить оформление, заполнить карточку приложения в VK Dev и подать на публикацию. Редактирование `vk-mini-app` само по себе не изменяет работающий сайт: для обновления отдельного пути `/vk/` потребуется отдельная выкладка.
