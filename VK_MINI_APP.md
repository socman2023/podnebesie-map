# Карта Поднебесья — адаптация для VK Mini Apps

**Ветка разработки:** \`vk-mini-app\` в \`socman2023/podnebesie-map\`.
**Статус:** техническая адаптация; приложение **ещё не зарегистрировано, не связано с App ID и не опубликовано в каталоге ВК**.

Основной сайт 2.0 на GitHub Pages не меняется. Исходные \`locations.json\` (128 объектов), \`images/\`, \`map-preview.webp\`, \`map-full.webp\`, \`map-base.png\` остаются общими с сайтом.

## Что добавлено

- Подключён локальный браузерный VK Bridge **2.15.12** (\`vendor/vk-bridge/browser.min.js\`) без загрузки JavaScript с внешних CDN.
- При запуске **из среды ВК** отправляется \`VKWebAppInit\`. В обычном браузере запросы к ВК не отправляются.
- URL \`#place=academia\` сразу открывает карточку Академии после загрузки данных.
- Выбор объекта обновляет адрес браузера и \`VKWebAppSetLocation\`, а системные \`popstate\`/\`hashchange\` и \`VKWebAppChangeFragment\` возвращают нужную карточку или карту.
- «Поделиться картой» и «Поделиться местом»: в ВК — \`VKWebAppShare\`, вне ВК — Web Share API / копирование ссылки. При известном \`vk_app_id\` ссылка будет вида \`https://vk.com/app<APP_ID>#place=academia\`.
- «В избранное» доступно только внутри ВК (через \`VKWebAppAddToFavorites\`).
- Учтены \`safe-area-inset\` и значения \`insets\` из \`VKWebAppUpdateConfig\`.
- Нет запроса персональных данных, токенов, уведомлений или прав к профилю.

**Примечание:** на некоторых версиях настольного VK клиент может игнорировать параметр \`link\` события \`VKWebAppShare\`. После создания приложения следует отдельно проверить распространение **конкретной** локации в VK Desktop.

## Проверка и сборка

Локально (Node.js 22 или новее):

\`\`\`bash
python -m http.server 8000
# Открыть http://localhost:8000/#place=academia
\`\`\`

Собрать автономные статические файлы для ВК:

\`\`\`bash
npm run build
# Результат: build-vk/index.html, карта, данные, картинки и обе библиотеки.
\`\`\`

Результат можно разместить на любом доступном по HTTPS статическом хостинге либо на хостинге VK Mini Apps.

Автоматические тесты в \`.github/workflows/test-vk-mini-app.yml\`:
- обычный браузер без VK, прямые ссылки и отсутствие кнопки избранного;
- имитация VK Bridge на экранах 320, 390 и 900 px, \`VKWebAppInit\`;
- VK Share, VK Add to Favorites и синхронизация URL/истории;
- стандартная загрузка карты, поиск и мобильные карточки.

Имитация VK Bridge не заменяет испытание внутри **официальных мобильных клиентов ВКонтакте**.

## Как зарегистрировать и опубликовать

1. В [VK Dev](https://dev.vk.com/) создать **VK Mini App** типа мини-приложения; указать название **«Поднебесье — карта мира»** и описание. Отсюда получится постоянный **App ID**. Это должен сделать владелец соответствующего аккаунта/сообщества.
2. Выбрать вариант хостинга: предпочтительно **VK Mini Apps Hosting**, либо существующий HTTPS GitHub Pages по **отдельному пути**. Нельзя указывать просто URL действующей карты 2.0: в неё не включён VK Bridge.
3. Для VK Hosting:
   - Скопировать \`vk-hosting-config.json.example\` в \`vk-hosting-config.json\`.
   - Указать в \`app_id\` выданный числовой ID (в шаблоне установлен 0).
   - Запустить \`npm run build\`.
   - Установить инструмент \`npm install --save-dev @vkontakte/vk-miniapps-deploy@^1\`.
   - Для развёртывания использовать \`npx vk-miniapps-deploy\` после авторизации владельца приложения или передачи токена через \`MINI_APPS_ACCESS_TOKEN\` в среде запуска.
4. Указать в настройках приложения целевой адрес для мобильного веб-клиента и десктопа либо адрес VK Hosting. Проверить VK iOS, VK Android, m.vk и Desktop.
5. Подготовить иконку, обложку и скриншоты в размерах, которые потребует актуальная форма VK Dev; затем отправить приложение на публикацию и проверку платформы.

**Без App ID и доступа владельца к VK Dev приложение невозможно зарегистрировать или опубликовать от лица пользователя.** В GitHub нет и не должно быть токена ВК.

## Поддержка и безопасность

- \`main\` — действующая самостоятельная карта 2.0, изменения в неё из этой ветки автоматически не попадают.
- \`vk-mini-app\` — VK-адаптация и будущие изменения.
- \`vk-hosting-config.json\`, \`node_modules/\`, \`build-vk/\` исключены из Git.
- Номер VK-приложения считывается из проверяемой по формату страницы; **не используется** для авторизации. Если позднее появится бэкенд/платёж/персональные данные — обязательно проверять подпись launch-параметров на сервере, а не доверять \`vk_app_id\` или \`sign\` из строки URL.
- Для публикации URL конкретной локации в VK создаётся адрес вида \`https://vk.com/app<APP_ID>#place=<ID>\`. Перед запуском следует проверить переходы на устройствах.
