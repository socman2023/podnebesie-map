# Интерактивная карта Поднебесья — версия 2 (разработка)

> Рабочая ветка: **responsive-map-v2**. Опубликованный сайт из `main` не изменён.

## Что готово

- Адаптивная карта Leaflet 1.9.4 в системе координат `CRS.Simple`.
- Перетаскивание, масштабирование колёсиком, жесты pinch/drag на мобильных устройствах.
- Мобильный начальный масштаб для удобного чтения, кнопка «Вся карта».
- Маркеры с большой зоной нажатия, клавиатурной навигацией и названиями для скринридеров.
- Поиск названий, фильтрация, полный список объектов.
- Боковые карточки на компьютере, нижние панели на телефонах.
- Внутренние переходы между объектами и исправленные внешние ссылки на ВК.
- Все **128** существующих объектов и описания из `locations.json` сохранены.
- Ограниченная разрешённая HTML-разметка описаний вместо произвольного `innerHTML`.
- Ленивая подгрузка изображения карты: сначала `map-preview.webp`, затем `map-full.webp` при приближении.
- Если WebP отсутствует или не загружается, есть резерв `map-base.png`.

## Графические ресурсы

Основная карта имеет разрешение **6670 × 4764**. Координаты JSON измеряются в пикселях от левого верхнего угла исходной карты.

На втором Google Диске в папке `MAP` найден оригинальный `map-base.png` размером **34 094 932 байта**. Он остаётся мастер-изображением.

**В рабочую ветку установлены WebP-файлы из оригинала 34 МБ:** `map-preview.webp` — 432 126 байт (1668 × 1191), `map-full.webp` — 3 306 350 байт (6670 × 4764). Полноразмерная копия проверена по SHA-256 `bbe918334f8f1c4ad0788a7e1e3e8c01e8124a930971c9a12e1f9811a08b3eff`. Исходный PNG второго Диска сохранён без изменений. PNG, который был в GitHub, остаётся резервом при ошибке загрузки WebP.

Вспомогательный сборщик из старого PNG: `tools/build_map_assets.py`. **Не запускать без необходимости:** он перезапишет WebP из более качественного оригинала. Пример вызова:
```bash
python -m pip install Pillow
python tools/build_map_assets.py
```

## Как проверить локально

Находясь в папке репозитория, выполните:
```bash
python -m http.server 8000
```
После этого откройте `http://localhost:8000`. Важно: двойной щелчок по `index.html` без локального сервера не подходит из-за загрузки `locations.json`.

Leaflet 1.9.4 хранится локально в `vendor/leaflet/`, с проверенными SHA-256 файлов JS/CSS. Для Leaflet больше не нужен сторонний CDN.

## Автоматические тесты

GitHub Actions `Validate responsive Podnebesie map` запускает Playwright в Chromium и проверяет:
- количество и уникальность 128 локаций;
- desktop-поиск и карточки, внешнюю ссылку;
- 320/390 px, отсутствие горизонтальной прокрутки, поиск и нижние карточки;
- клавиатурное управление маркерами.

Отчёт и скриншоты сохраняются как artifact `podnebesie-responsive-qa`.
