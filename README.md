# Интерактивная карта Поднебесья — версия 2 (рабочая ветка)

Ветка: \`responsive-map-v2\`. Основная публикация на \`main\` не затронута.

## Что уже изменено
- Новый интерфейс для телефона, планшета и компьютера.
- Leaflet 1.9.4 в режиме \`CRS.Simple\` (никаких реальных GPS-координат).
- Увеличение/уменьшение и перетаскивание; на смартфоне — жесты масштабирования.
- Существующие координаты \`locations.json\` сохранены: 6670 × 4764 px, начало координат — левый верхний угол исходной карты.
- Семантические маркеры с клавиатурным доступом и увеличенной областью касания.
- Поиск, фильтрация категорий, список всех объектов.
- Боковая информационная панель на desktop, нижняя карточка на мобильных экранах.
- Исправлено открытие внешних ссылок: адреса http/https больше не трактуются как идентификаторы локаций.
- На обзорном масштабе часть маркеров не отображается ради читаемости; все объекты доступны в списке и поиске.
- Защита описаний от произвольной HTML-разметки при сохранении \`<b>\`, \`<br>\`, \`<i>\`.

## Изображение карты
В источниках второго Google Диска, \`MAP/map-base.png\`, найден мастер-файл размером 34 094 932 байта и разрешением 6670 × 4764 px. Его размеры соответствуют существующим координатам. **Мастер-файл в GitHub не публикуется**.

Сейчас ветка использует существующий \`map-base.png\` (12 400 579 байт) для совместимости. Следующий шаг — подготовить облегчённое превью и тайловую пирамиду из мастер-файла (для быстрой загрузки на телефонах). Не заменять исходник уменьшенной копией без предварительной проверки координат.

## Локальный запуск
Для \`fetch('locations.json')\` нужен локальный HTTP-сервер:

\`\`\`bash
python -m http.server 8000
\`\`\`

Открыть \`http://localhost:8000/\`. Библиотека Leaflet загружается с CDN и требует интернет-соединения.

## Критерии готовности до слияния с main
1. Проверить 320 / 360 / 390 / 430 / 768 / 1024 / 1440 px; портретную и альбомную ориентацию.
2. Протестировать pinch, drag, zoom, выбор точек, поиск, фильтры, мобильные карточки на реальных устройствах.
3. Проверить браузеры iOS Safari, Android Chrome и встроенный браузер ВК.
4. Проверить клавиатуру, экранный диктор, длинные описания, внешние ссылки.
5. Внедрить оптимизированные ассеты/тайлы из мастер-изображения и проверить время загрузки.
6. Проверить все 128 объектов по JSON; основную ветку обновлять только после приемки.

## Файлы
- \`index.html\` — разметка адаптивного интерфейса.
- \`style.css\` — стили для desktop/tablet/mobile.
- \`script.js\` — Leaflet, маркеры, взаимодействие и поиск.
- \`locations.json\` — без изменения данных.
- \`map-base.png\`, \`images/\` — исходные изображения текущей версии.
